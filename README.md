# ✅ TaskMaster

**A lightweight to-do list web app with a Bangla interface, dark mode and offline storage. No backend needed.**

## ✨ Features
- 📋 **Dashboard** (`index.html`) with a personalised welcome message (স্বাগতম! 👋)
- ➕ **Add tasks** (`add-task.html`)
- ⚙️ **Settings** (`settings.html`): switch between light and dark themes, or reset all data
- 💾 Tasks, theme and username are saved in the browser's **localStorage**, so everything works offline
- 🇧🇩 The interface is in Bangla

## 🚀 Run it
No install is needed. Just open `index.html` in your browser.
